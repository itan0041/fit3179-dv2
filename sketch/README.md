# Sketch

Place your hand-drawn A4 sketch here as `sketch.pdf`.

The marking rubric awards **0** for a sketch made with digital tools, and applies a **-3% penalty**
if the sketch is for a different topic than the submitted page. Draw it on paper, photograph or
scan it straight-on, and export it as a PDF named `sketch.pdf` in this folder.

See `SKETCH_BLUEPRINT.md` in the repository root for the panel-by-panel plan that matches this page.
